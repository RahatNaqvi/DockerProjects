Docker Projects Portfolio

This repository showcases my practical experience with Docker through a collection of diverse containerized projects. It includes a Flask web application, a Django framework setup, MySQL paired with Adminer for database management, a Flask-Celery-Redis architecture for asynchronous task processing, and a Prometheus-Grafana stack for monitoring and visualization. Each project demonstrates my ability to design and orchestrate multi-container environments using Docker and Docker Compose, reflecting real-world use cases in web development, background job management, data handling, and system observability.
